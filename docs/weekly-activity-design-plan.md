# 주차별 활동 요약 디자인 개선

2026-10-29 · Codex · UI 개선 · 로컬 검증 완료

---

> ✅ **결과** — 구분선·제목·여백으로 그룹을 구분하고 반복 목록은 3건부터 읽는다. 필요한 내용은 펼쳐 확인하며 현장명·핵심 수치·원본 이동을 유지했다.

## 방향과 사전 점검

대상은 현장·매장 활동을 검토하는 관리자와 잡매니저다. 흰 표면과 딥그린의 기존 업무 화면을 유지한다. 제목→핵심 수치→현장·활동→보조 메타 순서로 읽게 하고, 각 콘텐츠 그룹의 시작에 구분선을 두고 제목 크기와 일정한 여백으로 위계를 더했다. 기본 정보는 왼쪽에 정렬하며, 새로운 이미지·장식·애니메이션은 추가하지 않았다. 외부 디자인 레퍼런스 없이 기존 Vinext/React 화면을 다듬었다.

기존 데스크톱·모바일 화면에서 확인한 우선 문제는 ① 작은 제목과 약한 그룹 경계 ② 타임라인 10건·조치 6건의 기본 과노출 ③ 내부 반복 수평선 ④ 검색 제목 숨김과 여러 왼쪽 시작점 ⑤ 좁은 화면의 아이콘·텍스트·작은 조작 영역이었다.

| 사전 평가(5점) | 점수 | 화면 근거 |
|---|---|---|
| 정보 위계 | 2 | 내부 소제목과 메타가 비슷한 크기 |
| 구성 | 2 | 반복 목록이 주요 그룹 경계를 흐림 |
| 타이포그래피 | 2 | 페이지 안 제목 크기·굵기의 차이가 작음 |
| 간격 | 2 | 서로 다른 그룹과 반복 항목의 간격이 비슷함 |
| 색·대비 | 4 | 기존 중립색·딥그린 기반은 유지 가능 |
| 표면·경계 | 2 | 카드·행·세부 그룹마다 선이 반복됨 |
| 아이콘·그래픽 | 3 | 고정 칸과 텍스트 간격을 정리할 필요 |
| 모션 | 4 | 장식 모션이 적으며 동작 줄이기 지원 |

| 제품 일관성 | 3 | 기존 브랜드는 유지되지만 상세 읽기 리듬이 약함 |

## 구현

- `.weekly-content` 범위와 `app/briefing/detail.css`로 AI 요약·문제 진단·추이·검색·주차 목록을 같은 기준으로 정돈했다. 대시보드 미리보기에는 새 스타일을 적용하지 않는다.
- H2 20/18px·600, 주차 제목 18/17px, 내부 소제목 16px. 그룹 간격 32/24px·제목 아래 16px, 핵심 숫자 28/26px는 `app/zeniel.css`의 공통 `--zf-detail-*` 토큰으로 정의했다.
- 진단 변화·예정 일정·현장 요약·타임라인·후속 조치·주차 목록은 기본 3개다. 숨은 건수를 알리는 흰 보조 버튼으로 더 보기/접기를 제공하며, 방문 본문·특이사항은 개별 `details`로 펼친다. 목록을 줄여도 전체 집계 숫자는 유지한다.
- 대그룹(AI·진단·추이·조회·주차 기록)과 상세 그룹(변화·예정·현장·타임라인·후속 조치) 시작에 1px 중립 구분선을 두었다. 선 아래 24px/모바일 20px 간격을 확보하고, 같은 그룹 안 타임라인·진단 항목별 반복선은 제거했다.
- 이름·핵심 숫자를 강조하고, 날짜·담당자·출처는 중립색 12px 이상으로 낮췄다. 모든 주차에 반복되던 현재 미해결 건수는 후속 조치 그룹에서 현재 기준임을 명시한다.
- 검색 제목을 복원했다. PC 5칸·태블릿 2칸·모바일 검색/현장 전체 폭+연월 2칸을 적용했다. 검색 아이콘과 입력은 분리된 격자, 긴 텍스트는 줄바꿈하며 SVG는 축소하지 않는다. 모바일 입력은 16px다.
- 주차 변경·검색 변경 시 펼침을 초기화한다. 원본 방문 결과·후속 조치 이동과 기존 권한·집계 로직은 유지한다.
