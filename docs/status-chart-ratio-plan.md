# 운영 상태 차트 백분율·수치 구분 개선

2026-10-29 · 구현·검증 완료 · main 푸시

## 원인과 방향

운영 상태 막대는 최댓값을 분모로, 레이블은 전체 운영 중 대상 수를 분모로 사용해 같은 행이 서로 다른 비율을 전달했다. 기존 React/Vinext·상태색·균등 차트 격자를 유지하면서 전체 대상=100%의 공통 기준으로 맞춘다. 대상 수와 비율을 별도 열로 구분하고 가벼운0–100% 기준을 둔다. 제목·범례·본문은 항상 표시하고 접기 기능은 제거한다. 새로운 이미지·색·모션이나 외부 레퍼런스는 사용하지 않는다.

## 구현 기준

- 막대 = 상태 수/전체 운영 중 대상 수의 원비율, 표시는 정수 반올림%.
- 상태·막대·대상 수·비율의4열, 대상 수는 개 단위. 기본/모바일44px 조작·12px 글자.
- 대상0·개별0·100%·서로 다른 유형·비운영 대상 제외를 검증한다.
- 상태 분류와 기간/조직/현장·매장 필터·원본 이동은 유지한다.
- 공통 ChartPanel 접기 버튼·상태·전용 CSS 제거.
- 디자인 지침6.5·AGENTS 현재 디자인 결정·프로젝트 룰 동기화.
