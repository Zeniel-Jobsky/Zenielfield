## 2. 구현 결정 (기획안이 정하지 않았거나 현재 데이터로 구현할 수 없는 항목)

운영 기준이 확정되면 바꿔야 한다.

| 항목 | 구현 | 확정이 필요한 것 |
| --- | --- | --- |
| 긴급 | 이슈에 심각도 필드가 없다. `DxIssue.urgent`가 정의된 이슈가 하나도 없으면 '긴급' 지표를 `—`(기준 미확정)로 표시하고 순위에서 제외한다. 필드가 생기면 어댑터에서 `urgent`만 채우면 된다. | 승인된 심각도 기준과 저장 필드 |
| 기한 초과 | 미해결이고 기한이 오늘보다 이전인 이슈. 초과 일수 표시. | — |
| 반복 | 같은 대상(현장 본사 또는 매장)에서 같은 조치 유형이 직전 90일 안에 다시 등록된 이슈. 등록일을 모르면 반복으로 보지 않는다. | 반복 판정 기간·유형 체계 |
| 담당 미지정 | 담당자가 비었거나 활성 사용자 목록에 없는 미해결 이슈. | — |
| 우선순위 | 긴급 → 기한 초과 → 반복 → 담당 미지정 → 미해결 건수. 사업장 행마다 선정 이유를 칩으로 표시. | — |
| 현장 합계 | 사업장 = 현장. 자체(현장 본사) 이슈와 산하 매장 이슈를 구분 표시, 이슈 ID로 중복 제거. | — |
| 주간 신규·해결 | 신규는 등록일, 해결은 완료일 기준. 등록일 미확인 이슈는 신규에서 제외하고 그 건수를 표시. | 재개 이슈의 시각 기록 |
| 주말 기준 미해결 | 상태 변경 이력 계약이 없어 완료된 주차는 산출하지 않고 `—`로 표시. 이번 주는 현재 미해결. | 상태 이력 저장 |
| 증감 | 지난주 같은 요일까지(진행 중인 주) 또는 직전 주 전체(완료 주)와 신규 건수만 비교. 등록일 미확인 이슈가 있거나 비교 구간 이전 자료가 없으면 숨김. 시각은 저장하지 않아 '동시간'은 적용하지 못한다. | — |
| 다음 주 조치 | 선택한 주의 다음 주에 기한이 있는 미해결 이슈와 예정된 방문. | — |
| 사진 | 현재 첨부파일 기능이 없어 상세에서 안내 문구만 표시. | 첨부 기능 |
| 후속 확장 | 히트맵(사업장×문제 유형), 주간 추이, AI 요약은 구현하지 않았다. | 문제 유형 용어 |

## 4. 화면 검수 시나리오

데모 모드, 관리자·잡매니저 각각, PC와 모바일 390px. 결과는 아래 기록란에 남긴다.

1. 대시보드 진입 후 10초 안에 1순위 사업장과 선정 이유를 말할 수 있다.
2. 1순위 행 [근거·조치 확인] → 상세의 4단계가 순서대로 보인다 (클릭 1회).
3. [조치 등록·담당 변경] → 입력 패널이 열린다 (클릭 2회).
4. [담당 미지정] 칩 → 목록 합계가 칩 숫자와 같다.
5. 주차별 브리핑에서 지난 주차를 선택하면 "주말 기준 미해결 —"와 "집계 완료"가 보인다.
6. 운영 모드에서 연결 오류를 일으키면 [다시 시도]가 보이고, 눌러서 복구된다.

### 검수 기록 (2026-10-28, 데모 모드, 시스템 관리자, Edge 헤드리스 + 기기 에뮬레이션 PC 1280px·모바일 390px)

| # | 결과 | 비고 |
|---|---|---|
| 1 | 확인 (시간 측정은 안 함) | 첫 화면에서 1순위 사업장(가상 서비스 009현장)과 선정 이유(`기한+5일`)가 보인다. PC·모바일 모두 |
| 2 | 통과 | [근거·조치 확인] 클릭 1회로 상세가 열리고 1 문제 내용 → 2 방문 원문·사진 → 3 담당자·기한 → 4 조치 이력 순서. 모바일은 전체 화면 시트 |
| 3 | 부분 확인 | 상세에 [조치 등록·담당 변경]·[재방문 예약] 버튼이 있다. 눌러서 입력 패널이 열리는지는 확인하지 못함 |
| 4 | **확인 불가** | 데모 자료에서 담당 미지정 = 0건, 반복 = 0건이라 칩 숫자와 목록 합계를 대조할 수 없다. 단위 테스트(54개)는 통과 |
| 5 | 통과 | 지난 주차(10월 4주차)에서 `주말 기준 미해결 —`, `상태 이력 없음`, `집계 완료`가 표시된다 |
| 6 | **미수행** | 운영 모드(Supabase) 연결이 필요 |

그 밖의 관찰:
- 모바일 390px에서 가로 넘침이 없고(`scrollWidth 390`), 사업장 행이 세로 카드로 바뀐다 (C-04 확인).
- 지난 주차를 골라도 소제목이 "이번 주 주목할 변화"로 남아 있었다. "이 주차 주목할 변화"로 고쳤다.
- 현재 진행 중인 주(10.26~)는 신규 0건, 지난주 같은 요일까지 대비 `-38건`으로 표시된다. 데모 자료의 등록일이 지난주에 몰려 있어서 나온 값이다.
- 시나리오 3·4·6은 사람이 직접 확인해야 한다.
