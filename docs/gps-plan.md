# GPS 지점 자동 선택

기준: 2026-10-28.

## 동작

- 방문 등록(직접·AI) 화면 "GPS로 지점 자동 선택" → 현재 위치 측정
- 300m 안 가장 가까운 운영 중 현장·매장 자동 선택
- 300m 밖 → 가까운 3곳 거리와 함께 표시, 눌러 선택
- 대상 고정(계획 결과 입력·회차 연결) → "현재 위치 기록"만, 지점까지 거리 표시
- https·위치 권한 필요. 거부·실패 시 직접 선택

## 데이터

- 현장·매장 `data.lat`·`data.lng` (선택). 등록 화면 "현재 위치로 좌표 입력"
- 방문 `data.geo` = `lat·lng·accuracy·at·distance`. `distance`는 서버가 대상 좌표로 재계산
- DB 컬럼 변경 없음 (JSONB). 검증 `mutations.ts` → Edge `logic.js`
- 데모: 지역 중심 ±0.03° 가상 좌표

## 남은 것

- 운영 현장·매장 좌표 입력 (현재 없음 → 자동 선택 안 됨)
- 주소 → 좌표 변환(지오코딩) 미구현
- 방문 위치 보관정책·동의 문구 확정

## 매장 검색 · 주소 좌표 (2026-10-28)

- 공개 매장 목록 없음 → 내부 자료(CSV) 기준 생산
- 화면: 현장·매장 등록 "매장명 또는 주소로 검색" → 선택 시 주소·위도·경도 채움
- API: `GET /api/geo?q=` (로그인 필요), Kakao Local 주소 검색 → 결과 없으면 키워드 검색, 5건
- 일괄: `node --env-file=.env scripts/geocode-stores.mjs 매장.csv` → `매장-geo.csv` (lat·lng·matched·status)
- 입력 CSV 열 = `code,name,address`
- 필요: `KAKAO_REST_API_KEY` (로컬 `.env`, Sites secret). 현재 미설정
