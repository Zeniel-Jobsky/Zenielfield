# 대시보드 차트 그리드 정렬

2026-10-28 · Codex · 디자인 개선 · 로컬 검증 완료

---

> 💡 **기준** — 차트 6개를 모든 행에서 같은 너비 2열로 배치하고, 각 쌍의 제목·범례·본문 행을 공유한다.

## 구현

- 차분한 운영 화면의 질서를 회복하도록 좌우 열의 세로 기준선과 차트 쌍의 위·아래를 맞췄다.
- 기존 `6+6 / 5+7 / 7+5` 혼합 폭을 모두 `6+6`으로 통일했다. 차트 순서와 업무 의미는 유지한다.
- `.dashboard-chart-grid` 아래 두 차트씩 `.dashboard-chart-pair`를 두고 CSS subgrid로 제목·설명, 범례, 본문 3개 행의 높이를 공유한다.
- 차트 제목 18px/모바일 17px, 흰 표면·상단 1px 구조선, 열 24px·쌍 사이 32px/모바일 24px 토큰을 재사용한다. 추가 장식·모션은 없다.
- 패널 고정 높이와 내부 세로 스크롤을 사용하지 않는다. 태블릿·모바일에서는 공유 높이를 풀고 한 열로 자연스럽게 쌓는다.
- 범례를 공통 패널의 별도 슬롯으로 옮겨 범례가 있는 차트와 없는 차트의 본문 시작선을 맞췄다. 각 행의 본문은 데이터가 많은 쪽에 맞춰 늘어난다.
- 주별 추이 SVG는 ResizeObserver와 실제 SVG 표시 배율로 축·수치 글자를 화면에서 12px로 보정한다. 모바일 최대 높이 제한도 반영하고 최대 폭 560px는 유지한다.
- 잡매니저 홈의 운영 상태·방문 경과 쌍도 같은 균등 열을 사용한다.

## 화면 진단

주요 원인은 ① 행마다 다른 열 폭 ② 설명 줄바꿈에 따른 본문 시작점 차이 ③ 범례가 본문에 섞임 ④ 과거 레이아웃의 고정 높이·스크롤 규칙 ⑤ 좁은 데스크톱의 SVG 축 글자 축소였다.

| 항목 (5점, 육안 평가) | 전 → 후 | 근거 |
|---|---|---|
| 정보 위계 | 4 → 4 | 기존 제목·설명 크기 유지 |
| 구성 | 2 → 4 | 모든 행에 같은 세로 기준선 |
| 타이포 | 3 → 4 | 추이 축·수치의 실제 12px 유지 |
| 간격 | 3 → 4 | 제목·범례·본문 행 공유 |
| 색·대비 | 4 → 4 | 기존 상태색·텍스트 유지 |
