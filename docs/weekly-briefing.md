# 주간 활동 브리핑 구현

2026-10-27 · 기존 운영 화면과 통합 플랫폼에 추가. DB·API·인증·데이터·기존 집계 로직은 변경하지 않았다.

## 화면 연결

- 통합 대시보드: 기존 KPI 및 조직별 표 유지. 방문 관리 60% / 주간 브리핑 40% 배치. 모바일은 세로 전환.
- 이번 주 / 지난주 미리보기는 상단 기간과 별도로 해당 월요일~일요일을 표시한다. 조직·대상·검색 조건은 적용한다.
- 방문 결과·이력 아래에 주차별 활동 브리핑 메뉴 추가.
- 카드에서 진입하면 현장과 주차 선택을 전달한다. 최신 주차 기본 펼침, 자유로운 펼치기/접기.
- 원본 방문 결과 및 후속 조치 입력 패널을 재사용한다. 브리핑 전용 기록을 복제하지 않는다.

## 데이터 및 집계

- 기존 실제 운영은 서버에서 권한 검증 후 받은 `/api/data`의 방문·이슈를 재사용한다. 매장 확장 화면은 기존 데모 어댑터를 사용하며 데모 표시는 유지한다.
- 실제 방문일이 있는 완료 기록만 주간 활동으로 인정한다. 계획·취소·미래 실제일은 제외한다.
- 한국시간 기준 월요일–일요일. 실제 방문일 필드는 KST 날짜이며 감사 로그 시각은 Asia/Seoul 날짜로 변환한다.
- 방문 ID와 이슈 ID 기준으로 중복 제거. 현장/매장 실적은 원본 유형 유지, 브리핑 카드에만 상위 현장별로 묶는다.
- 매니저 필터는 현재 배정자가 아닌 기록의 실제 방문자 기준이다. 이슈는 해당 담당자 소유 또는 해당 방문에 연결된 것만 조회한다.
- 역할 권한 범위보다 넓은 대상을 요청하거나 조회하는 별도 API는 없다. 매장만 권한이 있는 경우 권한 있는 매장 기록만 상위 현장명 아래 표시한다.
- 현장명 검색은 산하 매장 포함, 매장명 검색은 해당 매장, 방문자 검색은 해당 방문자가 작성한 활동을 조회한다.
- 월 또는 사용자 기간의 경계 주차는 조회기간과 겹치는 날짜만 집계하며 실제 집계 범위를 표시한다.
- 활동 없는 주차는 빈 상태. 과거 기록을 현재 활동으로 보정하지 않는다.
- 미해결 수는 현재 처리상태이며 과거 스냅샷이 아니다. 주차별 숫자를 합산하지 않는다.
- 신규 이슈는 등록일 기준, 완료 조치는 완료일 기준. 등록일 미확인은 추정하지 않고 신규 건수에서 제외한다.
- 카드 정렬: 기한 초과 → 미해결 → 지연 → 최근 활동. 실제 활동 있는 현장 중 최대 3개.

## AI 및 후속 사항

현재는 목적과 주요 활동 원문을 발췌·중복 문구 제거해 표시한다. 외부 AI 호출 및 전송 없음. AI 확장 시 담당자 검토·수정·확정과 요약 버전 보존이 필요하다. 과거 시점의 이슈 상태 복원은 상태 변경 이력 계약이 확정된 뒤 별도 구현해야 한다.
