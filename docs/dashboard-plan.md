## 2026-10-28 AI 현황 브리핑 (요약 → 브리핑으로 재설계)

- 사용자 피드백: 부장이 비서 브리핑을 듣는 느낌이어야 한다. 숫자 나열이 아니라 흐름과 판단. 무엇을 요약할지는 관리자 도구 설정이고 요약 자체는 자동.
- 결과 구조: `headline`(지금 상태 한두 문장) · `flow`(최근 8주 흐름, 지난주 대비, 이대로 가면) · `focus`(먼저 챙길 곳 3–5, 클릭 이동) · `story`(문제가 어디 몰려 있나, 반복 요청, 현황 끊긴 곳) · `judgment`(누구에게 무엇을 언제까지) · `watch`(다음 주 볼 지표)
- 자동 생성: 다이제스트 지문(`digestKey`)을 브라우저 저장본과 비교 → 같으면 재사용, 다르면 0.7초 뒤 재작성, 없으면 작성. 버튼·체크 없음(오류 시 `다시 시도`, 같은 조건 `다시 쓰기` 링크만)
- 요소 선택: 설정 화면 `AI 현황 브리핑 요소`(관리자·사업부장) — 조직 비교·주별 흐름·후속 조치·이슈 유형·장기 미방문. 브라우저 저장(운영 공용 설정은 후속)
- 다이제스트에 추가: 지연·미등록 비중, 기한 초과 전주 대비, 60일+ 비중, 이번 주·지난주 이행률
