# 통합 대시보드 제목과 그룹 구분

2026-10-28 · Codex · 디자인 개선 · 로컬 검증 완료

---

> 💡 **방향** — 제목의 크기·굵기와 그룹 사이 여백으로 업무 정보를 구분한다. 흰 표면과 상단 구조선을 유지한다.

## 기준과 구현

- 인상: 차분하게 업무 구역을 구분하는 운영 화면.
- 구성: 조회·지표 → AI 설명 → 차트 분석 묶음 → 사업장 진단 → 주간 브리핑 → 방문 대상 순서를 유지한다.
- 타이포: 실제 화면의 기존 H2 17px/모바일 16px를 18px/17px로 키우고 굵기를 500에서 600으로 조정한다.
- 표면·색: 기존 흰 표면, 중립 구조선과 텍스트 토큰을 재사용한다.
- 그래픽: 기존 차트·아이콘을 유지하고 제목과 차트 본문의 왼쪽 기준선을 맞춘다.
- 모션: 기존 동작을 유지하며 reduced-motion 환경에서도 확인한다.
- 구분 방식: 큰 그룹 사이 32px/모바일 24px, 차트 열 사이 24px·행 사이 32px/모바일 24px로 리듬을 만든다.

`app/platform/app.tsx`에 `.dashboard-content` 범위를 추가하고 `app/zeniel.css`에서 제목·그룹·본문 간격을 공통 토큰으로 관리한다. 다른 화면에는 새 제목 규칙을 적용하지 않는다.

## 화면 점검

주요 개선 대상은 ① 설명과 가까운 제목 크기 ② 차트 사이 좁은 간격 ③ 큰 그룹과 내부 간격의 유사성 ④ 제목·차트 본문의 다른 시작점 ⑤ 긴 제목과 우측 도구의 줄바꿈 여유였다.
