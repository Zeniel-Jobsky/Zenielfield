# 메뉴별 사용자 가이드

2026-10-29 · 원격 main `475280d`의 메뉴·연결 소스 기준. 실제 계정·운영 저장·외부 AI는 이번 문서 작업에서 시험하지 않았다. [문서 허브](../README.md)

## 시작하기

기본 화면에서 회사 계정으로 로그인한다. 등록된 활성 이메일·비밀번호 또는 이메일 링크를 사용하며 공개 회원가입은 없다. 인증 설정을 비우는 Sites 환경은 ChatGPT 인증을 사용한다. 데모는 로그인 화면의 ‘로그인 없이 체험하기’ 또는 ?mode=demo로 열며, 변경 내용은 메모리에만 저장하고 새로고침하면 초기화한다.

공통 조회 범위는 역할·조직·담당 대상에 따라 제한된다. 현재 범위 버튼을 펼치면 변경 가능한 단계만 보이며, 기간 선택에서 조회 기간을 바꾼다. 계정·새로고침·설정·로그아웃/로그인은 오른쪽 위 아바타 메뉴에서 찾는다. [메뉴 소스](../app/platform/app.tsx) · [계정 메뉴](../app/platform/account-menu.tsx)

## 운영 현황

AI 핵심 요약을 먼저 보고 핵심 지표·방문/후속 조치 차트·우선 확인 현장·주간 업무 요약을 확인한다. 역할별로 비교 대상이 달라진다. 잡매니저도 AI 요약을 먼저 보고 오늘 업무의 ‘지금 여기서 방문 기록’, 일정·미완료 조치로 이어진다. 숫자나 차트의 이동 버튼으로 원본 목록을 연다. 회차 이행률과 실제 방문 건수는 다른 값이다.

AI 요약은 조회 조건에 따라 작성한다. `AI 해석 더 보기`에서 반복되는 주제·전할 말·다음 주 볼 것·근거를 확인한다. `브리핑 접기`를 누르면 ‘무슨 일이 벌어지고 있나’만 남으며 `브리핑 펼치기`로 복원한다. 접힘 상태와 생성 결과는 해당 브라우저에 보관되며 다른 PC와 공유되지 않는다. 작성 중에는 ‘제니에리가 열심히 일하고 있어요’와 수집·분석·정리 단계가 표시된다. 실패 시 규칙 브리핑과 실패 이유를 표시한다. AI 문장은 참고용이며 실제 사실과 저장된 판정을 함께 확인한다.

## 현장·매장 관리

현장을 펼쳐 산하 매장을 보고 대상 이름으로 상세를 연다. 권한이 있는 사용자는 현장·매장, 도메인·조직·담당자·관리주기를 등록·수정한다. 현장 방문은 매장 전체 방문을 대신하지 않는다. 기존 이력이 있는 주기 변경에는 제한이 있다. GPS 자동 선택·주소 검색·좌표 입력 UI는 현재 꺼져 있어 대상을 직접 선택하고 기존 좌표는 보존한다.

## 방문 일정

월간·주간·목록 및 상태별로 조회한다. 등록에서 AI 또는 직접 입력으로 대상·방문자·예정일·시간·목적을 검토하고 저장한다. 계획은 결과를 기록해야 완료되며 예정일 경과로 자동 완료되지 않는다. 취소에는 사유가 필요하고 필요 회차가 없어지지 않는다. 일정 미리 찾기·후보는 기록된 사실과 현재 시간 조건을 사용한다.

## 방문 기록

완료 방문 원본을 조회하고 결과와 관련 후속 조치를 연다. 계획의 결과 등록 또는 계획 외 방문에서 대상·방문자·실제 일시·활동을 확인한다. AI 초안·문장 정리는 사람이 선택·검토하며 저장과 구분한다. 종합 판정은 저장된 AI 판정과 입력자 확인 흐름을 따른다. 화면에는 정상·지켜보기·조치 필요·바로 확인으로 표시하며 방문 이행률로 판정을 대신하지 않는다. 미판정·AI 대체 안내를 확인하고 자동 판정을 사실로 단정하지 않는다.

새 AI 방문 결과는 대상·담당자·활동 내용 외에 AI 초안이 있어야 완료 저장 버튼이 활성화된다. 첫 저장 동작에서 종합 판정을 요청하고 검토 후 다시 저장한다. AI 실패 시 `직접 입력`으로 전환해 내용을 확인·입력한다. 메모만으로 AI 폼에서 수동 완료 저장하거나 전환 시 메모가 자동 전달된다고 보장하지 않는다.

사진은 초안 입력에 사용할 수 있으나 원본 파일 보관·후속 열람 기능으로 안내하지 않는다. 방문 뒤 선택 조치를 순차 저장하므로 오류가 나면 방문과 조치 각각의 저장 결과를 확인한다. 방문 목록과 대상 상세 이력은 날짜 내림차순이다. 같은 날짜의 실제 시간·최근 이력 시각까지 정렬하는 개선은 해당 main에서 확인되지 않았다.

## 후속 조치

대상·담당자·기한·관련 방문을 지정하고 조치 예정·처리 중·보류·완료 상태를 관리한다. 현재 목록은 방문 기간과 별개인 현재 조치 상태를 보여준다. 모든 상태 탭에서 `목록 정렬`의 잡매니저별·기한 초과-내림차순·기한 초과-오름차순을 고른다. 잡매니저별은 현재 탭의 조치 건수가 많은 담당자순이다. 초과 일수는 미완료는 오늘, 완료는 완료일 기준이고 기한 내이거나 완료일이 없는 완료 건은 0일이다. 표와 모바일 카드는 같은 순서를 사용한다. 관련 방문과 대상이 일치하는지 확인하고 기한 초과·미완료 항목의 근거를 연다. ## 주차별 활동 요약

검색·대상·기간을 정해 현장별 활동, 전주 대비, 타임라인과 연결 조치를 확인한다. 긴 목록과 원문은 더 보기/활동 내용으로 펼친다. 원본 방문으로 이동할 수 있다. 실제 완료 방문을 한국시간 월요일–일요일로 묶는다. 기간 선택형 AI 핵심 요약은 별도이며 브라우저 지문별 보관을 사용한다. 현재 미해결 상태를 과거 주말 스냅샷으로 읽지 않는다.

## 통계·보고서

현장/매장과 조직별 필요 회차·실적을 비교하고 CSV·현재 화면 인쇄를 사용한다. CSV는 Excel에서 열 수 있지만 정식 XLSX 파일은 아니다. 내보낸 파일의 열·조건이 원하는 범위와 맞는지 확인한다.

## 설정

시스템 관리자만 도메인·사용자·활성 상태를 변경하며 운영 모드에서 로그인 비밀번호 발급·재설정을 수행한다. 역할별 범위는 [관리자 가이드](admin-guide.md)를 따른다. AI 브리핑 분석 요소 설정은 PC·브라우저에 저장된다. 계정·비밀번호 변경은 승인된 관리자 업무이며 원문을 문서나 채팅에 남기지 않는다.

## 오류와 한계

로그인 실패는 등록·활성 상태와 인증 방식을, 빈 목록은 기간·범위·상태를 확인한다. 저장 충돌은 최신 자료로 다시 검토한다. AI 실패 시 화면의 대체/직접 입력 경로를 사용한다. 사진 파일 보관·업무 알림·그룹웨어·정식 XLSX 등의 후속 범위와 과거 상태 복원 한계는 [기능 현황](feature-status.md)·[문서 점검](archive/documentation-audit-2026-10-29.md)을 참고한다.
