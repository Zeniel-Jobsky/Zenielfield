# 기능 현황

지금 동작하는 것과 운영 상태만 둔다. 날짜별 작업 기록은 [archive/changelog-2026-10.md](archive/changelog-2026-10.md), 다음 할 일은 [next-issues-plan.md](next-issues-plan.md)에 있다.

## 동작하는 기능

| 영역 | 기능 |
| --- | --- |
| 제니에리(AI) 정리 | 모든 메뉴 맨 위에 그 화면의 상황 질문과 대응 질문 정리를 둔다. 줄마다 바로 하기 버튼(일정 잡기·결과 쓰기·조치 보기)과 받는 사람에게 보낼 말 복사가 있다 |
| 운영 현황 | 기준 시각, 제니에리 말풍선, 브리핑(무슨 일 → 어디에 무엇이 → 어떻게 대응 → 더 보기), 지표 4개, 조직 공백표 + 주별 이행률 꺾은선, 오늘·이번 주·안 끝난 조치 각 5줄 |
| 방문 일정 | 방문 길라잡이(추천 이유 문단 + 이번 주 추천 동선 그림: 잡힌 방문 점 = 결과 등록, 추천 점선 점 = 그 날 일정 등록), 달력(잡매니저 월간, 파트장 이상 주간), 일정 등록 추천(먼저 가 보면 좋은 곳 5곳·정렬 칩·후보 날짜) |
| 방문·조치 | 방문 결과와 후속 조치를 한 화면에 둔다. 탭(조치 │ 방문)이 있고, 방문 줄 아래 그 방문의 조치를 보인다. 관리 열은 아이콘과 두 글자로 한 줄에 둔다 |
| 입력 | AI 간편 등록(말·사진·회의록), 직접 입력, AI 문장 정리(`aiEdits`), 저장할 때 AI 종합 판정을 사람이 확인 |
| 활동 요약 | 기간 브리핑과 날짜 축 타임라인 |
| 담당·주기 관리 · 현장 주소록 | 현장·매장 계층, 복수 담당·배정 이력, 관리 주기·필요 회차, 주소록 |
| 설정 | 내 계정(프로필·본인 비밀번호·제니에리 움직임), 사용자·권한(찾기·필터·표, 명단 CSV 양식·올리기 → 미리 보기 → 일괄 반영), 관리 도메인, 브리핑 내용 |
| 로그인 | 회사 계정 메일 + 비밀번호, 메일 로그인 링크(PKCE, 회사 SMTP를 연결해야 운영 가능), 데모 모드(저장 안 함) |
| 운영 도구 | 배치 실행기 `scripts/rollout.mjs`(단계·승인 게이트), DB 도구 `scripts/db.mjs`(상태·백업·초기화·이관·활성화 현황), 명단 적재 `provision-accounts --csv`, 화면 캡처 `npm run screenshots` |
| 배포 | main 푸시 → 검증 → (백엔드 변경 시) 이관 → 번들 → Edge 2개 → Cloudflare Worker. 연결 DB는 `ops/db-targets.json` |
