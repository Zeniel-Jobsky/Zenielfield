# 사업장 문제 진단 기획안

원본: `사업장문제진단추가기힉.pdf` (3쪽). 아래는 원문을 옮긴 것이며, 수치는 모두 가상 예시다. 이 문서는 원문 보관용이므로 수정하지 않는다. 구현 결과, 요구사항 추적표, 기획안과의 차이는 [계획 001](../plans/001-site-problem-diagnosis.md)에 있다.

사업장 문제 진단은 **통합 대시보드**에서는 현재 위험을, **주차별 활동 브리핑**에서는 주간 변화를 보여주도록 설계한다. 두 화면 모두 제목·공통 필터 아래에 배치하며, 기존 콘텐츠는 그 아래 유지한다.

## 1. 대시보드: 현재 위험과 우선 조치

관리자가 첫 화면에서 우선 대응 사업장을 찾도록 한다. 기본 화면은 요약 지표와 상위 3개 사업장만 표시하고, 전체 비교는 펼쳐본다.

```
통합 대시보드
[사업부 ▾] [팀 ▾] [사업장 검색]
─────────────────────────────────
사업장 문제 진단                    현재 기준 10.27 14:00
[긴급 3건] [기한 초과 8건]
[반복 4건] [담당 미지정 2건]
※ 지표 간 중복 포함 · 전체 미해결 18건

우선 확인 사업장                                [전체 보기]
사업장        주요 문제        상태·담당
A물류현장     안전통로 적치    긴급 · 김담당
B매장         주말 인력 부족   기한+3일 · 이담당
C서비스현장   고객 불만 재발   반복 · 담당 미지정
각 행: [근거·조치 확인]

[사업장별 문제 분포 펼치기 ▾]
─────────────────────────────────
기존 방문 현황 → 주간 브리핑 → 팀별 현황
```

- '긴급'은 승인된 심각도 기준으로 판단하고, 건수가 적어도 먼저 노출한다.
- 이어 기한 초과·반복·담당 미지정을 고려하며, 각 행에 선정 이유를 표시한다.
- 미지정 문제는 목록 순위와 관계없이 요약 지표에서 바로 접근한다.
- 펼친 영역에는 **사업장×문제 유형 히트맵**을 제공한다. 셀에는 미해결 건수를, 별도 표식에는 긴급 여부를 표시한다. 인력 수급·근태·노무·안전·서비스 품질·고객사 요청·미분류를 사용하되 운영 용어에 맞춰 확정한다.

## 2. 주차별 브리핑: 발견과 개선

같은 요약 카드를 복제하지 않고, 선택한 주에 무엇이 달라졌는지 보여준다.

```
주차별 활동 브리핑
[2026년 10월 5주 ▾] [사업부 ▾] [팀 ▾]
─────────────────────────────────
이번 주 사업장 문제 진단
10.26~11.01 · 현재까지 잠정 집계

[신규 6건] [해결 4건] [현재 미해결 18건]
지난주 동요일·동시간 대비 신규 +2건

이번 주 주목할 변화
신규 │ A현장 안전통로 적치 발견
해결 │ B매장 주말 인력 충원 확인
반복 │ C현장 동일 유형 고객 불만 재발
각 행: [관련 방문·원문 보기]

다음 주 조치 예정
D현장 │ 근태 개선 확인 │ 11.03 │ 박담당
[연결된 조치 보기]  [주간 추이 펼치기]
─────────────────────────────────
기존 사업장별 활동 브리핑 목록
```

- 완료된 주차는 '주말 기준 미해결'로 표시한다.
- 이번 주와 지난주 전체를 비교하지 않으며, 비교 시점을 맞출 수 없으면 증감을 숨긴다.
- 다음 주 조치는 실제 등록된 기한·방문 일정에서 가져온다.

## 3. 공통 사항

- 두 화면의 항목을 누르면 PC는 우측 패널, 모바일은 전체 화면 상세가 열린다. **문제 내용 → 방문 원문·사진 → 담당자·기한 → 조치 이력** 순서로 보여주고, 기존 조치 등록·담당 지정·재방문 예약으로 연결한다. 모바일에서는 사업장 행을 세로 카드로 전환한다.
- 집계는 이슈 ID로 중복 제거한다. 현장 합계는 자체 이슈와 산하 매장을 구분하고 공동 담당자 때문에 건수를 늘리지 않는다.
- 대시보드 문제 영역은 조직·사업장 필터만 적용하며, 방문 기간과 별개인 '현재 기준'을 명시한다.
- 주간 집계에는 생성·완료·재개 시각이 필요하고, 과거 상태 이력이 없으면 주말 잔여 건수를 추정하지 않는다.
- 최소 구현은 요약·우선 목록·상세 연결이다. 히트맵과 추이, 근거가 연결된 AI 요약은 후속 확장으로 둔다.
- 로딩은 자리표시자, 오류는 재시도, 권한 제한은 접근 불가로 표시하며 '이슈 없음'과 '점검 자료 없음'을 구분한다.

## 4. 검수 기준

- 우선 문제를 **10초 내** 식별하고, **2회 이내 클릭**으로 근거 확인과 조치 화면에 도달한다.
- 지표와 상세 목록 건수 일치, 주차 경계·재개 이슈·중복 집계도 함께 검증한다.
