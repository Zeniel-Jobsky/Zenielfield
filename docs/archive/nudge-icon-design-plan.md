# 운영 현황 메시지 아이콘 개선

2026-10-29 · Codex · UI 개선 · 배포 완료

---

> ✅ **결과** — 얼굴·팔 캐릭터를 메시지별 업무 아이콘 3종으로 교체했다. 첨부 SVG의 도형·선·여백을 참고하며 기존 사이트 색과 메시지 선택 로직은 유지한다.

## 방향과 근거

관리자·잡매니저가 숫자와 다음 행동에 집중하는 업무 화면에 맞춘다. 차분하고 명확한 인상을 목표로, 64×64 캔버스·2.5 단위 라운드 선·한 가지 업무 오브젝트와 작은 상태 표시를 공통 형태로 삼았다. 첨부 `bookscript.svg`의 접힌 문서, `project.svg`·`classroom.svg` 등의 단순한 면과 선을 참고했다. 13개 첨부 SVG를 비교했으며 외부 레퍼런스·새 이미지 생성은 사용하지 않았다. 기존 React/Vinext SVG 컴포넌트를 직접 수정했다.

사전 점검의 우선 문제는 얼굴·팔 캐릭터의 업무 화면과의 이질감, 밖으로 튀는 느낌표·반짝임, 손 흔들기·통통 모션의 시선 분산, 말풍선의 추가 테두리, 상태마다 달라지는 외곽 형태였다. 위계2·구성3·타이포4·간격3·색3·표면3·그래픽2·모션2·반응형3·제품 일관성2점(각5점)으로 평가했다. 변경 범위는 이 안내의 아이콘과 머리 줄에 한정한다.

## 메시지별 표현

| 기존 mood | 새 아이콘 | 기존 선택 조건 |
|---|---|---|
| joy | 체크 문서 | 저장 직후 또는 남은 일 없음 |
| cheer | 달력·다음 화살표 | 일정 잡을 회차가 남음 |
| concern | 현장·확인 표시 | 저장된 판정에 위험이 있음 |

- `zf-mascot`·mood 클래스와 `Mascot` API를 보존했다. `buildNudge`의 상태 선택·문구·숫자·버튼 동작은 변경하지 않았다.
- 44px(운영 현황)·56px(저장 안내) 크기, 중립 바탕·딥그린 선·기존 selected 채움으로 통일했다. 확인 필요 배지에만 기존 danger 색을 쓴다. 첨부의 베이지·세이지·코럴은 사이트 팔레트에 추가하지 않았다.
- 그림은 SVG 안에 모두 들어온다. 얼굴·손동작·기울기·밖으로 튀는 표시·반짝이와 관련 keyframes를 제거했다.
- 아이콘 옆은 12px 간격의 평문 제목(16px·600, 모바일15px)이다. 말풍선 테두리·꼬리·팝 효과를 제거하고 가변 텍스트 칸은 `minmax(0,1fr)`로 줄바꿈한다.
- 장식 SVG는 `aria-hidden`·`focusable=false`, 의미는 기존 메시지로 전달한다. 진행 막대·숫자·저장 직후 `+n`과 reduced-motion 처리는 유지한다.

## 검증

- 실제 운영 현황 데모에서 390px·820px·1280px의 아이콘·메시지 정렬과 줄바꿈을 확인했다.
- 실제 `Mascot` 컴포넌트의 3상태×2크기(44/56px)를 개발 브라우저에 렌더링해 모양과 선명도를 확인했다. 이 비교 화면은 검증용 DOM이며 제품에 추가하지 않는다.
- 6개 조합에서 SVG 애니메이션 없음·장식 숨김·포커스 제외를 확인했다. reduced-motion 설정에서도 정적 아이콘을 유지한다.
- 타입 검사·전체 테스트·디자인 검사·`git diff --check`·빌드 통과. 빌드 버전 `0.1.8`.
- 실제 운영 데이터 저장·저장 완료 흐름·로그인·배포는 이번 아이콘 검증에서 실행하지 않았다. 저장 안내의 56px 아이콘은 같은 컴포넌트 렌더링으로 확인했다.

화면 캡처와 첨부 비교 시트는 git 제외 `outputs/nudge-icons-20261029/`에 보관한다.
