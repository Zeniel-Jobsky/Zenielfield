# 기한 초과 후속 조치 정렬

## 모든 상태 탭으로 확대

### main 반영 전 최종 검증

최신 origin/main `89a36cb`와 충돌을 해결하며 원격의 다른 화면 변경을 보존했다. 의존성을 잠금 파일대로 설치한 후 기존 전체 테스트·정렬 전용 회귀 테스트·타입 검사·디자인 검사·빌드(v0.1.14) 통과. 정렬 테스트를 npm test에 포함했다. 최종 빌드 미리보기에서 Edge 390·820·1280px의 7개 탭 × 3개 정렬, 빈 탭·키보드 포커스·넘침 및 운영 현황·방문 기록 필터 정렬을 재검증했다. 실제 200% 브라우저 확대와 휴대폰 실기기는 미확인.

- 전체 이슈·미처리·조치 예정·처리 중·보류·완료·기한 초과에 같은 정렬 선택을 제공한다. 기존의 기한 초과 탭 한정 적용을 대체한다.
- 담당자별 건수는 현재 탭 목록 기준이다. 초과 일수는 미완료는 오늘 기준, 완료는 실제 완료일 기준이다. 기한 내는 0일이며 완료일이 없는 완료 건은 초과 여부를 추정하지 않고 0일로 취급한다. 동률은 처리기한·등록일·ID순이다.
- 공통 선택 컴포넌트와 스타일을 재사용했다. 타입·디자인 검사·빌드(NO_BUMP=1) 통과. 빌드 미리보기 5173에서 Edge 390·820·1280px 모든 7개 탭 × 3개 정렬 순서, 빈 탭, 포커스와 가로 넘침 검증 통과. 200% 확대·실제 휴대폰은 미확인.

## 이전 구현 기록

2026-10-29

- 후속 조치 목록의 기한 초과 탭에 목록 정렬 선택을 추가했다. 잡매니저별은 사용자 후속 요청에 따라 현재 조회 목록에서 담당자별 기한 초과 건수가 많은 순으로 변경했다. 건수 동률은 이름·담당자 ID, 같은 담당자는 오래 초과한 순이다. 기한 초과-내림차순은 오래 초과한 순(기본), 오름차순은 적게 초과한 순이다. 날짜 동률은 등록일·ID로 고정한다.
- 원본 배열을 변경하지 않으며 기존 조회 범위·권한·다른 상태 탭 정렬은 유지한다. 표와 모바일 카드가 같은 정렬 결과를 공유한다.
- 공통 입력·색 토큰을 사용하고 44px 선택 영역, 명시적 레이블, hover·키보드 포커스 표시와 좁은 화면 줄바꿈을 적용했다. 지침 7절·AGENTS 현재 디자인 결정·PROJECT_RULE DC-DESIGN을 함께 갱신했다.
- Edge 브라우저 390·820·1280px: 각 옵션에서 18개 항목 전체 정렬 검증, 포커스, 탭 이동 시 옵션 숨김, 가로 넘침 없음 확인. 1280px 스크린샷 검토. 실제 휴대폰·200% 확대는 미확인.
- 타입 검사·디자인 검사·빌드(NO_BUMP=1) 통과. 최초 빌드는 실행 중인 로컬 미리보기가 dist를 사용해 실패했고, 해당 서버를 중지한 후 재실행해 통과했다.
- `node tests/run-platform.mjs`는 기존 실행기의 esbuild 의존성 누락으로 실행하지 못했다. 실제 브라우저에서 정렬 순서를 검사했다. 커밋·푸시·공개 배포 없음.
- 담당자 건수순 변경 후 타입·디자인·빌드 검사 통과. 빌드 미리보기 5173에서 Edge 390·820·1280px의 18개 항목에 대해 담당자별 건수 내림차순 및 기존 날짜 양방향 정렬·포커스·다른 탭에서 숨김·넘침 없음을 재검증했다.
