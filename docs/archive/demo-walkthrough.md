# ZeniField 개선 보고 및 시연 안내

작성일 2026-10-28 · 대상: 사업부·팀 관리자 · 시연 시간 약 15분

ZeniField는 잡매니저의 현장·매장 방문을 기록하고, 관리자가 "어디가 밀리고 있는지"를 바로 보게 하는 운영 앱입니다. 10월 27일에 받은 첫 버전과 비교해 무엇이 달라졌는지, 시연에서 무엇을 보여 드리면 되는지 정리했습니다.

## 1. 무엇이 달라졌나 (한 장 요약)

| 구분 | 처음 받은 버전 | 지금 버전 | 현업에 주는 의미 |
| --- | --- | --- | --- |
| 들어가기 | ChatGPT 계정으로만 로그인 | 회사 이메일·비밀번호로 로그인. 체험(데모)은 로그인 화면에서 따로 | 외부 계정 없이 직원 누구나 사용 |
| 첫 화면(대시보드) | 숫자 카드와 표만 있고 그림(차트) 없음. 같은 숫자가 여러 곳에 반복 | 핵심 지표 4개 → AI 현황 요약 → 차트 6개 → 문제 사업장 → 이번 주 브리핑 순서. 숫자는 한 자리에만 | 보고서 없이도 5분 안에 현황 파악 |

## 2. 시연 순서

데모로 들어가면 가상 데이터로 모든 기능을 써 볼 수 있고, 저장해도 실제 DB에는 남지 않습니다.

1. **로그인 화면** — 회사 계정 입력란을 보여 주고 "로그인 없이 체험하기"로 들어갑니다.
2. **대시보드 (관리자 시점)**
   - 위쪽 기간·팀 필터를 바꾸면 핵심 지표 4개(이행률, 지연·미등록, 기한 초과 이슈, 60일 넘게 안 간 매장)가 바뀝니다.
   - **AI 요약** 버튼을 누릅니다. "먼저 챙길 곳"에 나온 팀 이름을 누르면 그 팀 화면으로 이동합니다. "조건 바뀌면 자동 요약"을 켜고 파트를 바꾸면 요약이 자동으로 갱신됩니다.
   - 차트에서 이행률이 낮은 팀 행을 누르면 그 팀의 파트 비교로 내려갑니다.
   - **사업장 문제 진단**에서 "기한 초과"를 누르고 사업장 하나의 "근거·조치 확인"을 엽니다.
3. **잡매니저 시점으로 전환** — 맨 위 **"지금 여기서 방문 기록"**을 누릅니다. 가까운 지점 3곳이 뜨고 방문 계획이 자동 연결됩니다. "직원 2명 결원, 냉장고 고장 수리 요청" 한 줄을 적고 저장하면 후속 조치 2건이 함께 등록됩니다.
4. **이미 적은 기록 다듬기** — 방문 일정에서 "결과 등록 → 직접 입력"으로 들어가 띄어쓰기가 엉킨 문장을 넣고 **AI로 정리하기**를 누릅니다. 바뀌는 칸만 비교해서 보여 주고, 체크한 칸만 반영됩니다. 저장 후 방문 결과 목록에 "AI 정리 1회" 표시가 붙습니다.
5. **주차별 활동 브리핑** — 지난주 대비 변화와 현장별 요약을 보고, 요약에서 원본 방문 기록을 엽니다.
6. **현장·매장 관리 / 후속 조치 관리 / 통계·보고서 / 설정** — 계층 구조, 조치 상태, 팀별 표와 인쇄, 사용자·권한 설정을 차례로 보여 줍니다.
7. **폰 화면** — 같은 데모를 폰으로 열어 하단 메뉴와 한 줄 배치, 등록 화면을 보여 줍니다.

## 3. 시연 전에 확인할 것

- 화면 맨 아래에 버전과 배포 시각이 보입니다. 시연하려는 버전과 같은지 확인합니다.
- 실제 운영 서버로 시연한다면 두 가지가 끝나 있어야 합니다. ① 로그인 계정 발급 ② "보는 기간만 받기" 운영 반영. 반영 전에는 첫 화면이 4–6초 걸립니다.
- 데모에서 AI 기능은 실제 AI를 부르지 않고 규칙으로 만든 예시를 보여 줍니다(화면에 "데모 …"로 표시). 실제 AI 문장은 운영 서버에서 확인합니다.

## 4. 아직 남은 일

- 운영 서버 반영: 기간 창 조회, AI 정리 기록용 DB 제약, 서버 함수 재배포 — 배포 담당자 작업 대기.
