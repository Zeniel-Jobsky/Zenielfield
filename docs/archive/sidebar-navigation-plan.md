# 로고 아래 중복 안내 제거와 좌측 메뉴 정리

2026-10-29 · 로컬 구현·검증 완료

## 방향

로고에 이미 있는 서비스 설명을 다시 보여 주는 조직 안내 카드와 워크스페이스 소제목을 제거한다. 기존 React/Vinext의 흰 사이드바·딥그린 현재 메뉴를 유지하며 로고→메뉴24px와 기존 메뉴 격자로 곧바로 탐색하게 한다. 새 색·이미지·장식 모션 없이 기존 로고와 메뉴만으로 위계를 만든다. 외부 레퍼런스는 사용하지 않는다.

## 구현 범위

- `app/platform/app.tsx`: 중복 조직 카드·소제목 제거.
- `app/sidebar.css`: 로고→메뉴24px, 사용하지 않는 안내 카드 스타일 정리.
- 공통 CSS: 제거한 요소의 전용 선택자만 정리, 다른 UI 규칙 유지.
- 디자인 지침5절·AGENTS 현재 디자인 결정·프로젝트 룰 DC-DESIGN-LOGO 동기화.
- 메뉴 순서·권한·알림·접기/펼치기·모바일 포커스 이동 유지.

## 검증

- 로컬 데모390/820/1280px와 200% 확대에 해당하는640 CSS px 재배치 확인. 브라우저 자체 줌은 수행하지 않음.
- 모든 폭에서 조직 카드/소제목 없음·메뉴8개·로고→메뉴24px·가로 넘침 없음. 아이콘x30px·텍스트x61px로 항목별 왼쪽 정렬 일치.
- 항목 높이 PC·태블릿46px/모바일48px, 로고 잘림 없음.
- 접힌 메뉴76px·ZF 표시·일반 로고 숨김, 다시 펼치기 정상.
- 방문 기록 메뉴 이동·해당 H1 표시·aria-current=page 확인.
- 모바일 Shift+Tab 포커스가 메뉴 안에서 유지되고 Escape로 닫힌 뒤 열기 버튼으로 복귀함.
- 브라우저 오류0·경고0. 타입 검사·전체 테스트·디자인 검사·git diff --check·Cloudflare 대상 빌드 성공(0.1.11).
- 운영 로그인·실제 데이터 저장은 수행하지 않음. 메뉴는 조회 데이터와 무관하므로 데이터 빈 상태·오류 상태 로직은 변경하지 않음.

사용자 요청(2026-10-29)에 따라 검증한 변경과 빌드 버전0.1.11을 함께 커밋·main 푸시 대상으로 반영한다. 푸시 후 GitHub 자동 배포가 실행되며 공개 배포 완료는 이 기록에서 확인한 것으로 표시하지 않는다. 캡처는 git 제외 `outputs/sidebar-navigation-20261029/`에 보관한다.
