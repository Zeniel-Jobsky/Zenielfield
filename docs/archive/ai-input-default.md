# 방문 등록 기본 = AI 입력

기준: 2026-10-28.

- 신규 방문 일정·결과 등록, 계획→결과 입력 = AI 입력 화면으로 열림
- 직접 입력 = 화면 상단 "직접 입력" 전환 또는 기존 직접 입력 기록 열람·수정
- AI 일정 등록: 말·글 → `/api/assist` `mode:'plan'` → 대상명·예정일·시간·목적·사전 확인 → 대상명으로 현장·매장 매칭 → 검토 후 저장(planned)
- AI 결과 등록: 말·글·사진 → 초안 → 검토 → `entry:'ai'` 저장
- 진입 시 위치·마이크·카메라 권한 요청, 용도 표시, 모두 허용 시 한 줄로 접힘, 거부해도 직접 선택 가능
- 위치 허용 시 GPS 자동 선택 (300m 안), 밖이면 가까운 3곳 접힘 목록
